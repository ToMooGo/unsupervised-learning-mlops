Label the 50 cluster-representative images

K-Means grouped the 1,347 training images into 50 clusters; these are the images closest to each centroid. Labelling just these (3.7% of the data) is enough to train the semi-supervised model. Labels are stored in PostgreSQL; retrain with LABEL_SOURCE=human to use them.
